# Greensworks - Design. Build. Simplify.

Thoughtful interfaces. Useful websites. Less repetitive work.

My interests sit where design meets technology:
brand identities, web experiences, and tools that make everyday
work easier.

## How I approach things

Start with the purpose.
Make the next step clear.
Pay attention to the details.
Look for ways to make everyday tasks simpler.

I’m interested in how a visual idea becomes a working experience,
and how design and technology can support each other along the way.
